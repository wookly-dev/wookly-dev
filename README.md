### `~/products/NetLoom`

**네트워크를 발견하고, 연결을 이해하세요.**  
Windows용 무료 IPv4 네트워크 점검 도구입니다.

- **장치 탐색** — 같은 네트워크의 장치와 기본 정보를 확인합니다.
- **연결 시각화** — 2D/3D 토폴로지와 연결 행렬로 관계를 살펴봅니다.
- **점검 결과** — 발견한 장치와 네트워크 정보를 정리하고 내보냅니다.

### `~/products/CheckMyWeb`

**내 웹사이트를 밖에서 보듯 점검하세요.**  
HTTPS·보안 헤더·노출 파일·메일 도메인 설정을 점검하는 무료 명령줄 도구입니다.

- **보안 점검** — 인증서와 HTTPS 전환, 보안 헤더·쿠키, 노출 파일, 메일 도메인 설정을 확인합니다.
- **서버별 조치** — 감지한 웹 서버와 CDN에 맞는 설정 예시를 보여 줍니다.
- **보고서** — 등급과 우선 조치 항목을 HTML·JSON 보고서로 남기고, 여러 사이트를 한 번에 점검합니다.
