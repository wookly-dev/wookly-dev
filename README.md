### NetLoom

**네트워크를 발견하고, 연결을 이해하세요.**  
Windows용 무료 IPv4 네트워크 점검 도구입니다.

- **장치 탐색** — 같은 네트워크의 장치와 기본 정보를 확인합니다.
- **연결 시각화** — 2D/3D 토폴로지와 연결 행렬로 관계를 살펴봅니다.
- **점검 결과** — 발견한 장치와 네트워크 정보를 정리하고 내보냅니다.
